Polityka prywatności — VEX

Data: 2026-11-14

Polski

  • Aplikacja VEX jest prywatnym asystentem jednej osoby (właściciela).
  • Aplikacja używa wyłącznie zakresu Google Calendar events (https://www.googleapis.com/auth/calendar.events) dla jednego konta właściciela.
  • Dane wydarzeń są przetwarzane wyłącznie w celu dodawania i sprawdzania terminów oraz przypomnień.
  • Dane nie są sprzedawane ani udostępniane osobom trzecim.
  • Tokeny dostępu są przechowywane na prywatnym serwerze właściciela.
  • Dostęp można cofnąć w: myaccount.google.com → Bezpieczeństwo → Aplikacje innych firm (Third-party apps with account access).

English

  • VEX is a private assistant for a single person (the owner).
  • The application uses only the Google Calendar events scope (https://www.googleapis.com/auth/calendar.events) for one owner account.
  • Event data is processed solely to add and check appointments and reminders.
  • Data is not sold and not shared with third parties.
  • Access tokens are stored on the owner's private server.
  • Access can be revoked at: myaccount.google.com → Security → Third-party apps with account access.
